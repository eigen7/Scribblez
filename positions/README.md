# Positions

This directory contains various game positions. Some come from interesting tournament positions.
Others were manually generated to produce interesting but realistic situations. A comment atop
each .gcg file indicates which.

These positions are intended to be used for systematic and ad-hoc analysis of neural network
and agent behavior.

`positions.json` specifies which turns of each game should be used for analysis. These turns are
1-indexed, so 1 refers to the first move of the game.
